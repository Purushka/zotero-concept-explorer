# 概念探索 0.2.8 · Concept Explorer

在 Zotero 中选词解释、沿子概念继续探索，并保留本地知识树。

## 安装

下载本页 Assets 中的 **`concept-explorer-0.2.8.xpi`**，在 Zotero「工具 → 插件」中从文件安装，随后重启。`Source code` 压缩包用于开发。

升级覆盖同一插件即可；原有知识树、解释、追问和草稿保留。本版采用手动更新。

## 本版更新

- 新增语言选项：跟随 Zotero、简体中文、繁體中文、English。立即切换并在重启后记住选择，无须先配置模型或 Key。
- 界面、工具菜单、阅读器按钮、浮窗及删除确认框同步切换。新生成的解释和追问回答使用所选语言；已有内容保留原文。
- 移除页头与空白页的 logo，保留插件名称。
- 延续浮窗拖动与四边吸附、原生 Zotero 标签页、节点和分支删除、Markdown/公式渲染及本地存档兼容。
- 提供中英文安装、模型配置、隐私及开发说明。浏览器和原生测试支持通过环境变量选择本地工具。

## 模型与数据

需要自备模型服务、模型名和 API Key。支持 OpenAI 兼容 Chat Completions、Responses 及 Anthropic Messages。模型服务可能计费。

知识树保存在本机 Zotero 数据目录；Key 使用 Zotero/Mozilla 的登录凭据存储。仅在解释、追问或测试连接时请求配置的模型服务。

## 验证范围

- 121 项 Node 测试。
- 66 项 Chromium 界面检查：阅读 32、删除 12、浮窗拖动 17、多语言 5。

- 模型接口使用虚构凭据和本地模拟 SSE，没有验证真实付费接口或模型答案质量。

清单声明 Zotero 8–10 兼容；本次没有逐一验证其他版本、macOS 或 Linux。

## English

Download **`concept-explorer-0.2.8.xpi`** from Assets, install it from Zotero's **Tools → Plugins**, and restart Zotero. GitHub's source archives are for development.

This release adds persistent language selection (Follow Zotero, Simplified Chinese, Traditional Chinese, English), live translation across native menus and panel surfaces, and removes decorative logos. New model answers follow the selected language; saved explanations and drafts keep their original text.

Existing popover dragging, edge docking, native tabs, knowledge-tree persistence, confirmed node/branch deletion, Markdown and math support are retained. Bring your own model/API key. Updates are manual.

Validation: 121 Node tests, 66 Chromium checks, and 29 native checks on Windows Zotero 10.0.6 using synthetic data and a localhost mock model service. Other host/platform combinations and real-model answer quality remain unverified.
