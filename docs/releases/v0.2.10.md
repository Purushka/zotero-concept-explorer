# 概念探索 0.2.10 · Concept Explorer

## 安装与升级

下载本页 Assets 中的 **`concept-explorer-0.2.10.xpi`**，在 Zotero「工具 → 插件」中从文件安装，随后重启。覆盖安装保留原有设置和本地知识树。本版采用手动更新。

## 本版修复

- 修复模型将正文换行多转义一层，导致页面显示字面的 `\n` / `\r\n`。遇到段落、标题、列表或显示公式等排版线索时恢复实际换行。
- 支持被包成一层或两层 JSON 字符串的 Markdown；修复结构化解释中公式换行与 TeX 命令的混淆。
- 修复覆盖新解释、流式输出、追问和历史解释。代码中的字面 `\n`、Windows/UNC 路径以及 `\nu`、`\nabla` 等公式命令会保留。历史内容在打开时恢复显示，不改写原记录。
- 解释与追问提示词补充正确换行和转义要求。沿用公式输入预览、原生 PDF 高亮关联、多语言和无 logo 界面。

- **138 项 Node 测试**。
- **71 项 Chromium 检查**：阅读 32、删除 12、浮窗 17、多语言 5、公式和批注 5。
- **35 项 Zotero 原生检查**：Windows / Zotero 10.0.6，首次运行 26 项、完整进程重启 9 项。模拟 SSE 返回错误转义文本，检查最终标题、段落、列表与公式布局，并回归高亮恢复、删除和取消生成。

换行恢复采取保守策略：没有排版线索的单个字面换行、未闭合代码或与路径连在一起的歧义文本可能保留原样。用户输入和 PDF 原文不执行这项模型输出修复；PDF 抽取时丢失的公式符号仍需补入正确 TeX。

测试使用独立 profile/数据目录、假 Key 和 localhost 模拟 SSE，不使用日常文献库；未验证真实模型 API 或回答质量。原生点击测试使用批注侧栏，PDF 画布回退由 Chromium 检查。清单声明 Zotero 8–10 兼容，其他版本及 macOS/Linux 尚未逐一验证。Assets 中的 SHA256 和 validation JSON 对应本次验证的准确安装包。

## English

Install **`concept-explorer-0.2.10.xpi`** from Assets through Zotero **Tools → Plugins**, then restart. Existing settings and knowledge trees are retained. Updates remain manual.

This release repairs model-generated Markdown with over-escaped line breaks (`\n` / `\r\n`) when paragraph, heading, list, or display-math layout supplies evidence. It also handles Markdown wrapped in one or two JSON strings, and distinguishes JSON newlines inside display math from TeX commands. New explanations, streaming output, follow-ups, and reopened historical explanations share this normalization. Code escapes, Windows/UNC paths, and commands such as `\nu` and `\nabla` are retained. Saved historical records are not rewritten.

Recovery is conservative: ambiguous single literal breaks, incomplete code, and path suffixes may remain unchanged. It applies to model output; user input and PDF selections are preserved. Lost PDF notation cannot be reconstructed reliably.

Validation: **138 Node tests, 71 Chromium checks, and 35 native checks** on Windows / Zotero 10.0.6. Native tests use the exact XPI, synthetic localhost SSE, dummy credentials, and independent profile/data directories, including process restart and highlight/conversation regressions. Native newline assertions inspect completed output; Node tests cover intermediate normalization. Other hosts/platforms, real API services, and answer quality remain unverified.
