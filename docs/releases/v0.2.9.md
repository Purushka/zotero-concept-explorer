# 概念探索 0.2.9 · Concept Explorer

## 安装与升级

下载本页 Assets 中的 **`concept-explorer-0.2.9.xpi`**，在 Zotero「工具 → 插件」中从文件安装，随后重启。GitHub 的 Source code 压缩包用于开发。

覆盖安装即可，原有设置和本地知识树继续保留。本版采用手动更新。

## 本版更新

- 公式统一渲染：原文选段、简述、详细解释、输入预览、用户消息和模型回答支持分式、求和、上下标等 TeX 公式。行内使用 `$...$`，独立公式使用 `$$...$$`；长公式可横向滚动。
- PDF 选段提问会创建或复用原生高亮。点击高亮、批注侧栏卡片或「查看对话」恢复已有会话，不重新请求模型。
- 删除高亮会删除关联会话及其后代分支、追问和草稿，并取消正在生成的相关回答。插件停用期间删除的高亮会在重新启用时清理对应会话。
- 高亮关联、对话与用户批注评论在重启后保留；重复选段复用原会话。保留原有多语言设置、无 logo 界面、浮窗拖动吸附和知识树功能。

## 使用边界

需要自备模型服务及 API Key。公式显示使用本地 KaTeX；PDF 文本抽取已经丢失的符号无法可靠还原，可在追问中补入正确 TeX。只有旧文本而没有选区坐标的历史记录不会自动补建高亮。PDF 需要可编辑批注的权限。

删除高亮会连带删除关联对话及子分支，没有一键撤销，重要内容请先备份。

## English

Install **`concept-explorer-0.2.9.xpi`** from Assets using Zotero's **Tools → Plugins**, then restart. Existing settings and knowledge trees are retained. Updates are manual.

This release renders TeX in source selections, explanations, live question previews, and both conversation roles. Use `$...$` for inline math and `$$...$$` for display math. Long equations scroll within the view.

Asking about a PDF selection creates or reuses a native highlight. Clicking the highlight, its sidebar annotation card, or **View conversation** restores the saved session without another model request. Deleting the highlight removes its linked conversations and descendant branches and cancels their running requests. Deletions made while the plugin is disabled are reconciled when it is re-enabled. Links, saved conversations, and user annotation comments survive restart.

Bring your own model service and API key. PDF extraction can lose mathematical notation; supply corrected TeX where needed. Old text-only records without coordinates do not receive highlights retroactively. Annotation editing must be allowed. Highlight deletion has no one-click undo; keep backups of important records.

Validation: **133 Node tests, 70 Chromium checks, and 34 native checks** on Windows / Zotero 10.0.6 with synthetic data and localhost SSE. Native click coverage uses the actual annotation sidebar; the PDF canvas fallback is covered in Chromium. Other hosts/platforms and real-model answer quality remain unverified. Package hashes and scope are included in the validation asset.
