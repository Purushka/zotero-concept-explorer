# 概念探索 0.2.12 · Concept Explorer

## 安装与升级

在本页 Assets 下载 **`concept-explorer-0.2.12.xpi`**，通过 Zotero「工具 → 插件」从文件安装，然后重启。覆盖安装保留设置和本地知识树；本版仍采用手动更新。

## 划词直接选择解释方式

- 原文划词菜单新增两个入口：**解释** 使用选文和附近上下文；**全文解释** 直接读取绑定 PDF 的全部可提取文本，结合选文回答。全文解释只发起一次请求，不先生成普通解释。
- AI 解释、追问回答中的划词菜单也提供这两个入口，用于继续创建子节点。
- 两个入口共用原有高亮和会话。普通解释打开已有回答时不重复请求；全文解释可在同一节点更新回答。正在普通解释时选择全文解释，会停止旧请求，避免迟到结果覆盖新答案。

## 支持整段选文

- 原文和 AI 正文的单次选文上限统一扩大为 **20,000 字符**，支持整段或多段文字；选文、公式和末尾内容完整保留并传入请求，不静默截断。超出上限请分段。
- 长段落在知识树和保留页中显示短标签，解释标题显示“选段解释”，完整原文仍保存在会话中。
- 提示词会要求解释整段的逻辑、结论和公式。沿用公式渲染、字面换行修复、发送／停止、输入框自适应、多语言、高亮回看与删除联动。

## English

Install **`concept-explorer-0.2.12.xpi`** from Assets through Zotero **Tools → Plugins**, then restart. Settings and local knowledge trees are retained; updates remain manual.

The native PDF selection popup and generated-answer selection menu now offer **Explain** and **Explain with full paper**. Explain uses nearby context; the full-paper entry starts one explanation request directly with all extractable text from the linked PDF. Both entries share the highlight and saved conversation. Switching an active local explanation to full-paper context cancels the old request and prevents stale results from overwriting the answer.

Both selection types now accept **20,000 characters**, supporting whole or multiple paragraphs without silently clipping the selection, equations or final lines. Long passages have compact navigation labels and a Selected passage heading while preserving their complete source. Prompts cover the selected paragraph's full argument. Existing math, newline recovery, Send/Stop, language options and highlight-linked conversations are retained.

Validation: **169 Node tests, 94 Chromium checks, and 51 native checks** on Windows / Zotero 10.0.6, with 40 first-run and 11 complete-process-restart checks against the exact released XPI. Native tests invoke the real selection hook, click both entries, extract the actual fixture PDF, compare complete paragraphs, cancel a superseded request and select generated text in Gecko. Actual mouse-drag selection on the PDF canvas was not separately automated.

Tests use synthetic localhost SSE, dummy credentials and independent profile/data directories. Other host versions/platforms, real API availability and answer quality remain unverified. Scanned PDFs require OCR, and full papers remain subject to provider context limits. Full text is only sent when chosen and is not archived. The archive schema remains 1. Package hashes and detailed validation are in Assets.
