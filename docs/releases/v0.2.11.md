# 概念探索 0.2.11 · Concept Explorer

## 安装与升级

下载本页 Assets 中的 **`concept-explorer-0.2.11.xpi`**，在 Zotero「工具 → 插件」中从文件安装，随后重启。覆盖安装保留原有设置和本地知识树。本版采用手动更新。

## 发送与停止

- 发送按钮改为蓝色圆形上箭头；读取全文或生成回答时，图标变为白色实心方块，点击即可停止。大页面和浮窗同步显示状态。
- 移除绿色“正在流式解释……”状态条，正文仍实时预览。
- **Enter 发送，Shift+Enter 换行**。中文输入法确认候选词不会误发送，连续回车只提交一次。生成期间可以继续编辑下一条草稿。
- 文本框取消右下角缩放手柄，随内容自动增高和收回；达到高度上限后在框内滚动。

## 结合全文重新回答

- 初始解释和每条 AI 回答下方新增 **“结合全文重新回答”**。点击后读取当前会话绑定的 PDF，将全部可提取文本交给已配置的模型，重新回答原问题。
- 使用 Zotero 官方 PDFWorker 提取全文；仅点击该按钮时发送全文，不截断正文，也不将全文写入本地知识树归档。
- 成功后原位替换所选回答，保留消息标识、后续对话和输入草稿；取消、提取失败或模型上下文超限时保留原回答。
- 沿用公式输入预览与输出渲染、字面换行修复、PDF 高亮回看与联动删除、简中／繁中／English 和无 logo 界面。归档格式仍为 schema 1。

## English

Install **`concept-explorer-0.2.11.xpi`** from Assets through Zotero **Tools → Plugins**, then restart. Existing settings and knowledge trees are retained. Updates remain manual.

The composer now uses a blue circular up-arrow. During PDF extraction or answer generation it becomes a solid white Stop square, synchronized between retained and floating views. The green status strip is removed while live previews remain. **Enter sends; Shift+Enter inserts a line break**. IME confirmation does not submit, repeated Enter sends once, and the next draft remains editable during generation. The textarea automatically grows and retracts, scrolls at its height limit, and has no resize grip.

**Answer again with full paper** is available below the initial explanation and each assistant answer. It reads the session's bound PDF using Zotero's PDFWorker and sends all extractable text with the original question and relevant history. Full text is sent only after this action, is not truncated, and is not archived. Success replaces the chosen answer in place while retaining message identity, later messages, and drafts. Cancellation, extraction failure, and provider context-limit errors retain the previous answer.

Math rendering, conservative newline recovery, native highlight-linked conversations, localization, and the logo-free interface are retained. The archive schema remains 1.

Validation: **163 Node tests, 88 Chromium checks, and 42 native checks** on Windows / Zotero 10.0.6, including actual full-PDF extraction and a complete process restart against the exact released XPI. Tests use synthetic localhost SSE, dummy credentials, and independent profile/data directories. Other versions/platforms, real provider availability, and answer quality remain unverified. Scanned PDFs require OCR; long papers can exceed the provider's context limit. Package SHA256 and detailed validation are included in Assets.
